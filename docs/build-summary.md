# Помойка — итог разработки

Обобщающий документ: что в итоге получилось из проекта «Помойка» (Telegram-only
агрегатор абсурдных новостей). Написан после завершения всех шагов роадмапа и
раунда правок по фидбеку. Для загрузки в чат, где обсуждалась идея и ТЗ, — чтобы
модель понимала актуальное состояние, а не только исходный замысел.

- **Репозиторий:** https://github.com/trenbolon2000/POMOYKA.IO (ветка `main`)
- **Канал:** https://t.me/pomoykaio
- **Бот:** @Pomoykaiobot (админ канала с правом постинга)

---

## 1. Что это в финале

Полностью автоматический конвейер:

RSS проверенных weird-разделов англоязычных СМИ → дедуп → дешёвый LLM-скоринг
абсурдности + safety-фильтр → рерайт на русском с дотяжкой полного текста статьи →
рендер карточки PNG → автопост в Telegram-канал по расписанию. Плюс суточный
дайджест-подборка без обращения к LLM.

Без сайта, фронтенда, платежей. Человек нужен только для промпта редактора и
периодической правки списка источников.

## 2. Как устроено

Два независимых GitHub Actions по крону:

**`pipeline`** (`*/30 * * * *`, каждые 30 мин):
1. `scripts/parse.js` — RSS активных источников → черновые записи в `news`.
   Отбрасывает записи без даты и старше `MAX_AGE_DAYS`. Дедуп по `original_url`
   (unique) + по нормализованному заголовку против последних ~200 записей.
2. `scripts/filter.js` — берёт необработанные записи (`absurdity_score IS NULL`),
   батч 40:
   - проверка домена по чёрному списку сатиры (в коде, до LLM);
   - **этап 1** (дёшево): заголовок + выжимка из RSS → `{is_absurd, score 1–10,
     safety_flag}`. Старые события / ретроспективы занижаются;
   - **этап 2** (только при `score >= REWRITE_THRESHOLD`, `!safety_flag`):
     скачивает полный текст статьи (`@extractus/article-extractor`), переписывает
     на русский → `{rewritten_title_ru, summary_ru}`. Правила: ровно одно матерное
     слово (обязательно), один абзац до 4 предложений. Проверка регуляркой + одна
     авто-попытка переписать при нарушении.
3. `scripts/post.js` — отбирает `score >= SCORE_THRESHOLD`, `!safety_flag`,
   `!posted`, есть рерайт, свежее `MAX_AGE_DAYS`. Публикует **не более 1 поста за
   запуск** и **не чаще 1 / `MIN_GAP_MINUTES`** (проверка по времени последней
   публикации). Рендерит карточку, шлёт `sendPhoto` с caption (заголовок / первое
   предложение выжимки жирным / остальное / источник + ссылка), проставляет
   `posted_to_telegram`, `telegram_message_id`, `posted_at`.

**`digest`** (`0 18 * * *` = 21:00 МСК):
- `scripts/digest.js` — топ-7 по `absurdity_score` среди записей с `posted_at` за
  последние 24 ч. Один пост-список: `title_rewritten` + ссылка на пост **внутри
  канала** (`https://t.me/pomoykaio/<message_id>`). Без вызова LLM. Карточка —
  фиксированное «Итоги дня».

**Отказоустойчивость (§8 ТЗ):** ошибка LLM (нет баланса / битый ключ) не помечает
запись обработанной и не роняет скрипт — подхватится следующим запуском. Запуск,
где не удалось обработать ни одной записи, инкрементит счётчик `llm_fail_streak`
в таблице `app_state`; на 3-м подряд — личное сообщение владельцу через того же
бота.

## 3. Технический стек (как реализовано)

- **Node.js 22** (обязательно ≥22 — `@supabase/supabase-js` v2 требует нативный
  WebSocket; на Node 20 падает).
- **Supabase** (PostgreSQL, free tier).
- **LLM:** OpenAI-совместимый эндпоинт, задаётся в `.env`. Сейчас **DeepSeek**,
  `LLM_BASE_URL=https://api.deepseek.com`, `LLM_MODEL=deepseek-v4-flash`. Код от
  провайдера не зависит (`lib/llm.js` — тонкая обёртка над `/chat/completions`,
  `response_format: json_object`, ретрай на невалидный JSON).
- **Telegram Bot API** — `sendPhoto` (multipart), `sendMessage`, `deleteMessage`
  не используется.
- **Рендер карточки:** `@napi-rs/canvas` (prebuilt-бинарники, без нативной сборки
  на раннере). Шрифты в репозитории: `assets/fonts/PTSans-{Bold,Regular}.ttf`,
  `PTSansNarrow-Bold.ttf` (OFL). Никакой ИИ-генерации изображений.
- **GitHub Actions cron.** Public-репозиторий → бесплатные минуты без лимита.

Зависимости: `@supabase/supabase-js`, `rss-parser`, `@extractus/article-extractor`,
`@napi-rs/canvas`.

## 5. Схема БД

**`sources`**: `id`, `name`, `rss_url` (unique), `region`, `active`.

**`news`**: `id`, `source_id` (FK), `original_url` (unique), `title_original`,
`content_original` (выжимка из RSS ~300–500 симв.), `title_rewritten`,
`content_summary`, `absurdity_score` (real, NULL = не обработано),
`safety_flag`, `source_published_at`, `fetched_at`, `posted_to_telegram`,
`telegram_message_id`, `posted_at`.

**`app_state`**: `key`, `value` (jsonb), `updated_at` — счётчик `llm_fail_streak`.

Записи с `safety_flag = true` сохраняются (для калибровки промпта), но никогда не
публикуются.

## 6. Источники: чем всё закончилось (главное отклонение от ТЗ)

ТЗ задумывало глобальный охват: UK/US таблоиды, немецкий Bild, французские
«faits divers» (Ouest-France, La Dépêche, Nice-Matin), испанские «sucesos»,
азиатские издания (SoraNews24, Coconuts, Times of India), мировые агентства
(Reuters/AP/AFP), африканская сеть Legit.

**На калибровке (≈600 записей прогнано через фильтр) выяснилось:** рабочий жанр
дают только выделенные weird/odd-разделы англоязычных таблоидов. Всё остальное —
это общие полит/крим-ленты, где 60–90 % записей получают `safety_flag` и весь
батч LLM уходит впустую, либо тёплый human-interest без абсурда (0 попаданий).

**Отключены и почему:**
- Bild News, El Mundo España, La Dépêche, Ouest-France, Times of India World —
  57–90 % safety_flag на тесте.
- 20 Minutes «Faits divers» — 90 % safety_flag: «faits divers» на практике =
  реальный криминал и ДТП, а не курьёзы.
- Legit.ng / Tuko / Yen / Briefly (разделы People, gist, buzz, gossip) — 112
  записей, 0 попаданий в порог. Выделенной рубрики «жареного» в RSS у сети нет.
- SoraNews24 — живой и свежий, но это потребительские курьёзы Японии (мерч, еда),
  0 попаданий на 40 записей.
- Coconuts — издание закрылось ~декабрь 2023, фид отдаёт архив 2015–2023.
- Vice Weird — раздел не обновляется с декабря 2025; общая лента = гейминг.
- The Sun News — невалидный XML (ломает sax-парсер) + почти весь hard news.
- Nice-Matin — все адреса фидов отдают 403/404/406 скриптам.
- Reuters / AP / AFP — публичные RSS закрыты, сторонние зеркала нестабильны.

**Активны сейчас (7):**

| источник | регион | роль |
|---|---|---|
| New York Post — Weird But True | US | ядро (лучший hit-rate) |
| Metro UK — Weird | UK | ядро |
| Daily Star — Weird News | UK | ядро |
| Express — Weird | UK | филлер |
| UPI — Odd News | US | филлер (чистый, почти без флагов) |
| Mirror — Weird News | UK | слабый, под наблюдением |
| Oddity Central | WORLD | профильный weird-news сайт, глобальные истории |

`db/seed-sources.sql` содержит все проверенные адреса, включая отключённые, с
комментарием-причиной у каждого.

**Реальный объём:** эти разделы издают мало. Ожидаемо **5–8 постов в день**, не
десятки. Владелец счёл это приемлемым («если новости свежие и правда смешные»).

## 7. Ключевые решения и отклонения от ТЗ

- **Порог публикации: 6** (ТЗ §7 требовало `>= 7`). Владелец снизил ради объёма.
- **Свежесть:** ТЗ прямо не требовало, но по фидбеку добавлено жёсткое правило —
  не парсить и не публиковать записи без даты или старше `MAX_AGE_DAYS = 10`.
  Плюс этап 1 занижает «старые события / подборки старых историй».
- **Темп:** 1 пост / 90 мин (`MIN_GAP_MINUTES`), 1 пост за запуск. Крон при этом
  тикает каждые 30 мин ради свежести парсинга.
- **Стиль рерайта:** ровно одно матерное слово на пост (обязательно, не ноль),
  один абзац до 4 предложений. Enforcement — регулярка + одна авто-попытка;
  DeepSeek иногда всё равно не матерится в нейтральных сюжетах (~85 % compliance).
- **Дотяжка полного текста статьи** для этапа 2 — этого в ТЗ не было. Добавлено,
  потому что weird-разделы отдают в RSS только заголовок, и рерайт по одной
  строке получался плоский. Скачивание только для прошедших порог (~единицы за
  прогон), при ошибке/пейволле — тихий откат на выжимку из RSS.
- **Карточка без ИИ-картинки.** Обсуждали генерацию (Flux schnell ~$1/мес
  укладывался в бюджет $10), но пока решено ограничиться типографикой на canvas.
  Дизайн: тёмный фон, кислотный логотип `POMOYKA.IO`, узкий condensed-заголовок
  капсом — верхняя половина строк цвета фуксия (`#ff249c`), нижняя кислотно-
  зелёная (`#ccff00`); гранж-рамка, лёгкий шум, нижняя строка с источником и
  векторными иконками. Категорий на карточке нет (владелец отменил).
- **Первое предложение выжимки** в caption Telegram — жирным (`parse_mode=HTML`).
- **Node 22** вместо изначально предполагавшегося 20 (техническое требование
  `@supabase/supabase-js`).

## 8. Параметры (крутилки)

| что | где | значение |
|---|---|---|
| Порог рерайта/публикации | `filter.js` / `post.js` | 6 |
| Макс. возраст новости | `lib/config.js` `MAX_AGE_DAYS` | 10 дней |
| Мин. интервал между постами | `lib/config.js` `MIN_GAP_MINUTES` | 90 мин |
| Постов за запуск | `post.js` `POST_LIMIT_DEFAULT` | 1 |
| Размер батча фильтра | `filter.js` `BATCH_DEFAULT` | 40 |
| Порог алерта об ошибке LLM | `filter.js` `FAIL_STREAK_ALERT` | 3 подряд |
| Крон пайплайна | `pipeline.yml` | `*/30 * * * *` |
| Время дайджеста | `digest.yml` | `0 18 * * *` (21:00 МСК) |

Секреты (`.env` локально, GitHub Secrets в проде): `SUPABASE_URL`,
`SUPABASE_SERVICE_KEY`, `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`,
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`, `TELEGRAM_CHANNEL_USERNAME`,
`OWNER_CHAT_ID`.

## 9. Текущее состояние

- Все 5 шагов роадмапа закрыты, + раунд правок по фидбеку, + редизайн карточки.
- `pipeline` и `digest` идут по расписанию, прогоны зелёные (проверено ~40+
  запусков).
- Тестовые посты из канала владелец удалил вручную (у бота лимит — удаление
  только сообщений моложе 48 ч).
- Калибровка ядра рабочая; жанр «паранормальное/мистика» после правки промпта
  тоже попадает в порог.

## 10. Известные хвосты / что можно докрутить

- **Объём.** Если 5–8 постов/день мало — снизить порог до 5, искать ещё
  weird-источники, или подключить генерацию картинок для «веса» контента.
- **Мат.** ~85 % постов получают ровно одно матерное слово; остальные выходят
  «чистыми». Можно добавить вторую попытку ретрая или сменить модель для этапа 2.
- **Старые события с свежей датой.** Таблоиды иногда перевыпускают историю
  многолетней давности с сегодняшним `pubDate` — фильтр по дате это не ловит,
  работает только правило в промпте этапа 1.
- **Тон рерайтов.** Правится примерами в `prompts/editor.md` (это зона владельца,
  код файл не трогает).
- **Mirror** — 2 попадания из 32 на тесте, кандидат на отключение по накоплении
  статистики.
- **Картинка в карточке** — обсуждали Flux schnell (~$1/мес) либо набор своих
  line-art иконок; решение отложено.
- **Дайджест за 8 сентября** вышел неполным: в ходе отладки промпта были обнулены
  `title_rewritten` у ~10 уже опубликованных записей, дайджест их не увидел.
  Разовое, дальше чисто.
